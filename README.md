# Silke Slootz

Website von Silke Slootz: Channeling, Tarot und systemische Begleitung (München). Statisch, ohne Build-Schritt.

- `index.html`: Startseite
- `index2.html`: Die Ebenen. Übersicht und je eine Seite pro Ebene (`#quelle`, `#schoepfer`, `#lichtwesen`, `#seelen`, `#astral`, `#erde`)
- `impressum.html`, `datenschutz.html`: Rechtstexte, gelb markierte Stellen ergänzen
- `styles.css`, `legal.css`: Gestaltung, Regeln in `DESIGN.md`
- `app.js`: Sprache, Menü, Ebenen-Seiten, Anfrage über WhatsApp
- `i18n.js`, `i18n2.js`: Übersetzungen EN, PT, ES. Deutsch steht im HTML
- `fonts/`: lokal gespeicherte Schriften
