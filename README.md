# Silke Slootz

Website von Silke Slootz: Medium · Channeling · Tarot · Systemische Begleitung (München).

Einfache statische Website (Deutsch/Englisch), ohne Build-Schritt:

- `index.html`: die ganze Seite inklusive Design und Sprachumschaltung
- `impressum.html`, `datenschutz.html`: Rechtstexte (gelb markierte Stellen noch ergänzen)
- `images/`: Bilder
- `fonts/`: Schriften, lokal gespeichert (keine Verbindung zu Google)

## Bilder austauschen

Die Seite nutzt vorläufig Ausschnitte aus dem Entwurf (`images/entwurf-*.jpg`) und gezeichnete Grafiken.
Sobald diese Dateien im Ordner `images/` liegen, werden sie automatisch verwendet:

- `silke-channeling.png`
- `silke-tarot.png`
- `familienaufstellung.png`
- `chakren-mensch-tiere.png`
